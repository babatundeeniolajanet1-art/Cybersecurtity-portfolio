🛡️ Virtual SOC Lab – Security Monitoring & Threat Detection

1. Project Overview

This project involved building a virtual Security Operations Centre (SOC) environment to explore security monitoring, authentication activity, security event investigation and network segmentation.

The lab provided a controlled environment for developing practical knowledge of SIEM operations, endpoint monitoring and network security.

2. Project Objectives

* Build a virtual SOC environment.
* Configure security monitoring using Wazuh.
* Explore authentication logs and security events.
* Understand how suspicious activities can be identified and investigated.
* Explore firewall configuration and network segmentation.
* Develop practical SOC monitoring and investigation skills.

3. Tools & Technologies

Tool	Purpose
Wazuh	SIEM and security monitoring
pfSense	Firewall and network segmentation
Kali Linux	Security testing environment
Ubuntu	Linux operating system and monitoring environment
VirtualBox	Virtual machine management

4. Lab Architecture

The virtual environment incorporated:

* Ubuntu as a Linux-based system.
* Wazuh for security monitoring and event analysis.
* Kali Linux for controlled security testing.
* pfSense for firewall and network segmentation.
* VirtualBox for hosting the virtual machines.

5. Practical Activities

Security Monitoring

Explored Wazuh capabilities for collecting and reviewing security events.

Authentication Monitoring

Examined authentication activity and Linux log information to understand how login events can support security investigations.

Network Security

Explored pfSense firewall functionality and network segmentation principles.

Security Investigation

Developed an understanding of how security events can be reviewed, investigated and documented within a SOC environment.

6. Security Investigation Approach

The investigation process focused on:

1. Reviewing available security event information.
2. Identifying unusual authentication activity.
3. Examining relevant log entries.
4. Understanding the context of security events.
5. Considering appropriate security controls and remediation measures.
