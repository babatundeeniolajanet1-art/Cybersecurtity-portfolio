Healthcare Phishing Incident Investigation Using Splunk

Project Overview

This project involved investigating a phishing incident affecting a healthcare organisation. A phishing email was sent to an employee, who clicked the embedded link.

I used Splunk SIEM during project and internship activities to investigate the incident, analyse relevant security event data, identify the user associated with the link clicks and establish how many times the link was clicked.

Investigation Objectives

* Investigate a phishing incident involving a healthcare organisation.
* Use Splunk to search and analyse relevant security events.
* Identify the user associated with the phishing link activity.
* Establish the number of times the phishing link was clicked.
* Review the recorded dates and times to understand the sequence of events.

Tools Used

* Splunk SIEM
* Security event logs
* Splunk Search

Investigation Activities

1. Used Splunk to search relevant security event data.
2. Identified the user associated with the phishing link clicks.
3. Reviewed the number of times the link was clicked.
4. Examined the recorded timestamps to establish the incident timeline.
5. Used the findings to support the investigation of the phishing incident.

Skills Demonstrated

* Splunk SIEM
* Security log analysis
* Phishing investigation
* User activity monitoring
* Incident timeline analysis
* Threat investigation
* SOC operations

Key Learning Outcomes

This investigation strengthened my practical understanding of how SIEM tools can support phishing investigations. It demonstrated the importance of analysing security events, identifying suspicious user activity and using evidence to support incident response.

Confidentiality
